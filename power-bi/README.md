# Power BI Report

This folder contains the Power BI Desktop report developed for the GB Electricity Market & Renewable Analysis project.

## Report Contents

The report includes:

- Interactive date filtering
- Market Index Price KPIs
- Embedded renewable penetration analysis
- Negative-price frequency analysis
- Intraday electricity-price analysis
- Daily Market Index Price trends

The Power BI model combines NESO electricity demand and embedded renewable generation data with Elexon Market Index Price data at settlement-period level.
